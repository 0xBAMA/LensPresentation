\newnotepage{Snell's Law - Refraction}
\begin{wrapfigure}{r}{0.38\textwidth}
    \centering
    \notegraphic{0.36\textwidth}{lens/snell.png}
\end{wrapfigure}
\begin{itemize}
    \item {\large Refraction happens when we transition between media of different index of refraction (IoR), $N_{\text{1}}$ and $N_{\text{2}}$}
    \begin{itemize}
        \item {\large This is a unitless property of the material, and we are just taking a ratio of the two}
        \item {\large The ratio of these two properties is inverted, when you are going the other direction (air into glass vs glass into air)}
    \end{itemize}
    \item {\large We can calculate the result of the refraction in ray optics using the GLSL refract() function}
    \begin{itemize}
        \item {\large Parameters are the surface normal, the incident ray, and the ratio of $N_{\text{1}}$ and $N_{\text{2}}$, referred to as eta}
        \item {\large Result is the refracted ray, or a zero vector if the refraction math fails}
    \end{itemize}
\end{itemize}

% =2=================================================
\newnotepage{Snell's Law - Wave Interpretation}
\begin{wrapfigure}{r}{0.32\textwidth}
    \centering
    \notegraphic{0.3\textwidth}{lens/airtowater.png}
\end{wrapfigure}
\begin{itemize}
    \item {\large The IoR property actually describes the propagation speed of light in that medium, relative to how fast it travels in a vacuum}
    \item {\large This gives rise to another interpretation based on wave optics... pulses of incident energy arrive at some rate, and the bending ocurrs as a result, because they share phase at the boundary}
    \item {\large The specifics here are a little bit out of scope, but we can say that this is a phenomenon that changes with the rate of the pulses ariving at the interface}
    \begin{itemize}
        \item {\large "Rate" here refers to the frequency of the incident light - this property corresponds to its color, as it is proportionally related to the wavelength of the light by the constant speed of light C}
        \item {\large This variation of IoR with respect to frequency is referred to as "Dispersion", and it is a key concept in optical systems - it is the same phenomenon that is depicted on the cover of Dark Side of the Moon, and which gives rise to rainbows when it ocurrs inside of water droplets in the atmosphere}
    \end{itemize}
    \begin{figure}[htbp]
    \centering
    \notegraphic{0.5\textwidth}{lens/disperse.png}
    \end{figure}
\end{itemize}

% =3=================================================
\newnotepage{Abbe Number and Cauchy Coefficients}
\begin{wrapfigure}{r}{0.32\textwidth}
    \centering
    \notegraphic{0.3\textwidth}{lens/abbe.png}
    \text{Ernst Abbe (1840-1905)}
\end{wrapfigure}

\begin{itemize}
    \item {\large It's important to have an expression for this behavior, if we want to be able to use it for a real application like an optical system - relevant for describing different types of glass, fluids, or atmospheric gasses}
    \item {\large Framework for describing this property came from Ernst Abbe in the mid-to-late 1800s, defining the index and Abbe number of optical glass}
    \begin{itemize}
        \item {\large These are defined at reference wavelengths of light - specific emission bands from luminous gas discharge provide a frequency reference that can be used to test a sample of a given material}
    \end{itemize}
    \item {\large The Cauchy Eqauation is from somewhat earlier, in 1830}
    \begin{itemize}
        \item {\large The most useful expression for our use here is the two term form}
        \[
            n(\lambda) = A + B/(\lambda^2)
        \]
    \end{itemize}

    \item {\large It is possible to derive the Cauchy Equation coefficients A and B corresponding to a given IoR and Abbe number, by this relation given by LuxCoreRender (using the d-, F-, and C-wavelength definitions):}
    \[
            B = \frac{ n_{d} - 1 }{ v_{d} } * \frac{ F^2 C^2 }{ C^2 - F^2 } = \frac{n_{d} - 1}{v_{d}} * 0.52
    \]
    \[
            A = n_{d} - B * 2.897      \;\;\;\;or\;\;\;\;     A = n_{e} - B * 3.354
    \]
    \item {\large They go on to explain that the difference between the two definitions is less than 0.05\% over the visible spectrum of light, and that the difference between using Cauchy and the more math-heavy Sellmeier Equation is similarly negligible}
\end{itemize}

\newnotepage{Lens Prescriptions}
\begin{wrapfigure}{r}{0.46\textwidth}
    \centering
    \notegraphic{0.42\textwidth}{lens/fisheye.png}
\end{wrapfigure}
\begin{itemize}
	\item {\large The term is probably more familiar from the opthamology field, the same is term is used here to describe a specification of a lens system}
	\item {\large This is an example fisheye design from Warren J. Smith's book Modern Optical Engineering}
	\item {\large Each line item is "an interface" in the system}
	\item {\large The parameters can be put in two categories}
	\begin{itemize}
		\item {\large Material Properties}
		\begin{itemize}
			\item {\large Index (IoR)}
			\item {\large Abbe number (often labeled $V_{\text{no}}$)}
			\item {\large Usually a code for a type of glass that fulfills this requirement, or "air" for air gaps}
		\end{itemize}
		\item {\large Geometric Properties}
		\begin{itemize}
			\item {\large Radius of curvature: this is element curvature, specifying convex, planar, or concave surfaces}
			\item {\large Thickness: this is the distance from this interface to the next}
			\item {\large Semiaperture: easy to confuse the abbreviation with with saggita, but this is equal to half the diameter of the element, what we see here as height}
		\end{itemize}
	\end{itemize}
\end{itemize}

\newnotepage{Processing and Visualizing Lens Data}
\begin{wrapfigure}{r}{0.46\textwidth}
    \centering
    \notegraphic{0.42\textwidth}{lens/sonnar.png}
	\text{Showing agreement between my 2D pathtracer and the reference}
\end{wrapfigure}
\begin{itemize}
	\item {\large Sectioned views like this are taking advantage of the radial symmetry of the system}
	\item {\large A lens system consists of one or more elements, in one or more groups - these are higher level organization structures which can be interpreted from the prescription}
	\begin{itemize}
		\item {\large An element is a piece of glass that can be manufactured, as a building block of a system like this - the surfaces can be ground into concave, planar, or convex profiles, with spherical or aspherical curvature}
		\item {\large A group is one or more elements grouped within the system - this can include things like cemented doublets and triplets, which are simple elements which are glued together with a material with properties such that it acts like a glass-glass interface}
	\end{itemize}
\end{itemize}

\begin{itemize}

	\end{itemize}
	\item {\large We can assign a 2-bit code to each interface, which gives us 4 possible values}
	\begin{itemize}
		\item {\large 00: air/air represents an aperture stop}
		\item {\large 01: air/glass is the front side of an element}
		\item {\large 11: glass/glass is between cemented glass elements}
		\item {\large 10: glass/air is the back side of an element}
	\end{itemize}
	\item {\large Why it matters? Building a system string like this, we can draw a better diagram now, and add cylinder geometry for the outer edge of these elements if desired}
	\begin{itemize}
		\item {\large It's also potentially useful information at runtime, to control the refraction/masking logic when tracing a ray through the system}
	\end{itemize}
\end{itemize}

\newnotepage{Tracing a Ray through the System}
\begin{itemize}
	\item {\large What is a "valid ray"? We're using a somewhat simplified model}
	\begin{itemize}
		\item {\large Starts at the film plane, with an associated wavelength, on the far right of our diagrams}
		\item {\large Visits each element, in order, performing the correct wavelength-dependent refraction using the Cauchy coefficients of the materials on either side of the interface}
		\begin{itemize}
			\item {\large The fact that there are no reflections is a key simplification for speed and it means that this system is not currently able to directly resolve lens flares at time of writing}
			\item{\large I'm interested in exploring this further, in the style of one of my prior experimental forward pathtracer projects called Newton, where primary rays are emitted from light sources and would only contribute to the image if they ultimately intersect a simulated film plane}
		\end{itemize}
		\item {\large Passes all aperture tests, both explicit aperture stops (e.g. a bladed iris) and those defined implicitly by the semiaperture of each element}
		\item {\large Arrives at the font surface of the front element, and is then ready to be traced against the scene}
	\end{itemize}
\end{itemize}

% =9=================================================
\newnotepage{Pupil Sampling - Motivation}
\begin{wrapfigure}{r}{0.3\textwidth}
    \centering
    \notegraphic{0.28\textwidth}{lens/pbrt3.png}
\end{wrapfigure}
\begin{itemize}
	\item {\large Viewed from the film plane, a lens system has what's called an exit pupil - this is the effective aperture of the system, which admits scene radiance}
	\item {\large In order to resolve the correct image at the film plane, you need to integrate all the radiance at the pupil - this is equivalently the incident radiance at the film plane (for our purposes)}
	\item {\large This graphic, from Physically Based Ray Tracing v3's Realistic Cameras chapter, shows a view of the system pupil from two distinct points on the film plane}
	\begin{itemize}
		\item {\large Somewhat counterintuitively, the one which is solid orange color is "in focus", as the incident radiance is uniform - we integrate, and get orange for this point on the film}
		\item {\large The green one where the pupil sees distinct leaves will need to integrate varying frequency image contents - when we perform the integration, it constitutes a blurring, and we see this as an "out of focus" portion of the image}
	\end{itemize}
	\item {\large We need an efficient way to sample this pupil radiance - when we do this integration for all points on the film, the result is the lens image that we want to resolve}
\end{itemize}

% =10================================================
\newnotepage{Establishing the Exit Pupil}
\begin{wrapfigure}{r}{0.3\textwidth}
    \centering
    \notegraphic{0.28\textwidth}{lens/fisheyerays.png}
\end{wrapfigure}
\begin{itemize}
	\item {\large At render time, starting from the film plane, we need a way to generate rays that will pass through the exit pupil of the lens}
	\item {\large In the image to the right, this graphic is drawing all ray paths, starting at the film plane on the right and traced as far as they continue through the lens system - those arriving at the left hand side are considered "valid", and have made it through the system... note how small a subset this is, of the total rays drawn}
	\item {\large Some sampling strategies, motivating our approach:}
	\begin{itemize}
		\item {\large Hemisphere Sampling - generate random directions in the hemisphere normal to the film plane... this can be $<$1\% efficiency, with very few rays making it the exit pupil}
		\item {\large Rear Element Sampling - generating random directions based on the vector from the flim plane to random points generated on the rearmost element of the system... this is more efficient than hemisphere sampling, and it is a much more efficient starting point}
		\item {\large Pupil Sampling - if we can, for example, put a bounding box around the exit pupil, and generate uniform samples in that box... it's a good starting point for sampling the image, and the rate of successful rays generated this way is approximately the ratio of the areas of a circle inside a square, $\frac{\pi}{4}$}
		\item {\large Importance Sampling of Pupil Radiance - this is still in the works in my pathtracer, Phoenix, but if we can accumulate some LUT of the pupil's radiance distribution, it will be able to resolve both a more efficient and a much more correct result... more about this in the discussion section at the end}
	\end{itemize}
\end{itemize}
